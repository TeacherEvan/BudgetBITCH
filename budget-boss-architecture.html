Budget Boss — System Architecture

Next.js 14 (App Router) + Convex · local-first PWA · auth-first client gate · offline IndexedDB → Convex sync

Client / Frontend

  • • Next.js 14 App Router (Server Components + selective 'use client')
  • • Root gate page.tsx routes: welcome / wizard / board
  • • Feature components: dashboard, wizard, accounts, shared-board, receipt
  • • Hooks + pure-TS modules (budgeting / home-base)
  • • Tailwind v4 · framer-motion · recharts · next-intl (6 locales)

Local-First + Auth

  • • IndexedDB (idb) — offline writes, syncQueue replay on 'online'
  • • Encrypted backup export/import (crypto-backup)
  • • Convex Auth Password provider; token in localStorage (webview-safe)
  • • Client guard: RequireAuth + route-guard over /dashboard, /accounts, /settings, /wizard
  • • PWA: public/sw.js, manifest, Web Share Target

Convex Backend

  • • HTTP ingest (convex/http.ts) /receipts/ingest bearer secret
  • • Server functions: accounts, sharedBoards, snapshots, legal, feedback
  • • Receipt engine: Gemini 2.5 Flash parseReceipt + deterministic lib/receipt
  • • Web Push (VAPID) via node action pushSend.ts
  • • 14-table schema + authTables; indexes required (no .filter/.collect)

Integrations

  • • LINE (TeacherBOY) → POST OcrPayload to /receipts/ingest
  • • Bank SMS parser (EU/SG/US/generic) → /sms-confirm
  • • Gemini 2.5 Flash OCR; Resend email verify
  • • RSS Market Watch + vicinity feeds (/api/news)
  • • VAPID web push notifications

Security Boundary

  • • Client trust boundary: auth-first gate, no middleware
  • • Convex identity derived server-side (ctx.auth.getUserIdentity)
  • • Ingest secret CONVEX_SYNC_SECRET; never pass userId from client
  • • CSP with per-request nonce (proxy); tesseract.js client OCR
  • • Encrypted local backups; legal/cookie consent audit trails

Data Flow

  • • User → Next.js → RequireAuth → Convex Auth (JWT)
  • • Writes: IndexedDB immediate → async sync to Convex
  • • Reads: hooks query Convex; offline falls back to IndexedDB
  • • Receipts: client OCR draft → /ingest → Gemini → confirm
  • • Shared boards: keyed-merge (boardMerge.ts) across members
