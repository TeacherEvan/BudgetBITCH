# Theme Tokens & Animation Patterns Reference

## Standard Tokens

- **Card Background (Dark)**: `bg-slate-900/90`
- **Border Utility**: `border border-slate-800`
- **Primary Action Gradient**: `bg-gradient-to-r from-violet-600 to-indigo-600 hover:from-violet-500 hover:to-indigo-500`
- **Focus Rings**: `focus:outline-none focus:ring-2 focus:ring-indigo-500/50`

## Transition Utility Standard

```html
class="transition-all duration-200 ease-in-out hover:scale-[1.01] active:scale-[0.99]"
```
