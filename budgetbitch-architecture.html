BudgetBITCH Architecture

Next.js + Convex + Gemini AI — Real-time Budget Tracking PWA

Frontend Stack

  • • Next.js 16 (App Router, RSC, Turbopack)
  • • React 18 + TypeScript 6 + Tailwind 4
  • • Convex React Client (Realtime)
  • • Clerk-compatible @convex-dev/auth
  • • next-intl i18n (en/th)
  • • PWA: Service Worker + Web Push
  • • IndexedDB via idb (offline-first)
  • • Vercel Analytics (opt-in)

Convex Backend

  • • Real-time DB + Functions (Queries/Mutations/Actions)
  • • Auth: Password + Email (Resend OTP)
  • • Tables: users, accounts, boards, snapshots, invites
  • • Scheduled: Client-driven daily snapshots
  • • Web Push: VAPID via web-push library
  • • Deployment: steady-ox-280.convex.cloud
  • • CI Guard: check-convex-deployment.mjs

AI / External

  • • Gemini 2.5 Flash (Receipt OCR)
  • • Structured JSON output (amount/merchant/category/date)
  • • Resend (Transactional Email)
  • • Web Push: FCM (Chrome) / Mozilla Push
  • • VAPID Keys self-managed in Convex env
  • • All secrets in Convex Dashboard / Vercel Env

Infrastructure

  • • Vercel: Edge CDN + Serverless Functions
  • • CSP/COOP headers via vercel.json
  • • Build: npm run build (Next.js + TypeScript)
  • • Preview: Auto on PR, Prod on main push
  • • Rollback: GitHub Action (vercel rollback)
  • • DNS: budget-bitch-green.vercel.app

Security / Compliance

  • • Strict CSP (script-src 'self' + vercel.live)
  • • COOP: same-origin-allow-popups
  • • Auth: HttpOnly JWT Cookies (Convex)
  • • Legal: Versioned Terms/Privacy acceptance
  • • Cookie Consent: Optional analytics
  • • Rate-limited Auth (10/hr per IP)

Data Model Highlights

  • • Accounts: Umbrella grouping (max 5 owned/user)
  • • Shared Boards: Up to 8 members per board
  • • Daily Snapshots: Full wizardProfile + totals
  • • Offline Queue: LWW by updatedAt, replay on sync
  • • Invites: Share code + QR token (pending/accepted)
  • • Push Subscriptions: One per browser endpoint
